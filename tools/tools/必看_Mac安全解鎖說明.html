⚠️ 首次執行必看：解除 Mac 安全限制

因為這個遊戲是由網路下載的開源軟體，Mac 的 Gatekeeper 安全機制會將其標記為「已隔離」(Quarantine)，並顯示「檔案已損毀」或拒絕執行。

請依照以下 5 個步驟，一次性解除安全限制（以後就可以直接點兩下玩了）：

步驟 1：確認整合包所在位置

首先，因為MacOS的權限與安全性限制，請先確認整合包在「home」目錄下，若不是，請將其移至「home」目錄下。

步驟 2：複製Ultima 7原始程式內容

然後，請在您原本的Ultima 7遊戲安裝目錄下，將「STATIC」資料夾，複製到整合包的「Ultima_7」資料夾下。

步驟 3：開啟「終端機」 (Terminal)

按下鍵盤的 Command (⌘) + 空白鍵 叫出 Spotlight 搜尋，輸入 Terminal 或 終端機 並按下 Enter。

步驟 4：複製解鎖指令

點擊右方的綠色按鈕，將解鎖指令複製起來：

xattr -cr

（注意：指令的最後面有包含一個空白，請務必一起複製。貼上到終端機後，先不要按 Enter！）

步驟 5：把Exult.app 拖進去並執行！

1. 在終端機視窗中，按下 Command (⌘) + V 貼上剛剛複製的指令。

2. 把資料夾裡面的 Exult.app 遊戲圖示，用滑鼠拖曳到終端機視窗裡面放開。

3. 此時終端機會自動補上遊戲的路徑。確認無誤後，按下 Enter 鍵。

🎉 完成！現在你可以關閉終端機，直接點兩下 Exult.app 開始遊戲了！

🎉 這動作只要執行一次就可以。
