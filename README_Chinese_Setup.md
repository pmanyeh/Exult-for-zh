# Exult 繁體中文版 - 遊戲內中文設定選單 (Chinese Setup) 說明

本說明文件針對 Exult 繁體中文版中全新加入的**「Chinese Setup（中文設定）」**選單進行詳細的操作與功能介紹。
這個選單讓玩家不需手動修改 `exult.cfg`，直接在遊戲內就能即時預覽並調整所有與中文顯示相關的設定。

---

## 1. 如何開啟中文設定選單

在遊戲中按下 `ESC` 鍵開啟主選單，依序點擊：
**Game Options (遊戲選項) -> Chinese Setup (中文設定)**

---

## 2. 操作邏輯與「儲存/取消」機制

為了讓玩家能安心地嘗試各種設定組合，中文設定選單導入了**「狀態快照 (Snapshot)」**機制：

* **即時預覽**：當您拖曳拉 Bar (Slider) 或點擊按鈕，並點擊OK後，遊戲畫面上的文字會**立刻改變**，讓您即時看到效果。
* **[ OK ] 按鈕**：點擊 OK 代表您「確認並保留」在這個頁面所做的所有變更。如果是子頁面，點擊 OK 會回到主設定頁面；如果是主設定頁面，點擊 OK 會將所有設定正式寫入設定檔並關閉選單。
* **[ CANCEL ] 按鈕**：點擊 Cancel 代表您想「放棄」這次在**當前頁面**的修改。
  * 在子頁面點擊 Cancel，系統會**自動還原**您剛進入該子頁面時的設定，並退回主設定頁面。
  * 在主設定頁面點擊 Cancel，系統會放棄您剛剛在主頁面上調整的項目（例如陰影、行距等），但**會保留您剛才在子頁面裡已經點擊 OK 確認過的心血**，然後關閉選單。

---

## 3. 自動字型掃描 (Auto Font Scanning)

在所有的子頁面中，第一個選項都是 **Font Type (字型)**。
系統會在遊戲啟動時，自動掃描以下兩個資料夾中的所有 `.ttf` 字型檔：
1. `<PATCH>/` (遊戲 Patch 目錄)
2. `<DATA>/` (Exult Data 目錄)

您可以透過點擊按鈕，在掃描到的所有字型檔之間循環切換。若選擇 `Default`，則代表使用繼承自上一層的預設字型。

---

## 4. 設定項目詳細說明

### 4.1 主設定頁面 (Main Page)

主頁面包含了三個通往子頁面的按鈕，以及影響全域的渲染設定。

* **Dialog Text Setup**：進入「對話文字/頭頂文字」設定子頁面。
* **Small Text Setup**：進入「書本/卷軸」設定子頁面。
* **Sign Text Setup**：進入「招牌/墓碑」設定子頁面。**在〔黑月之門〕暫無作用，之後會用於〔巨蛇之島〕的翻譯術。**

**全域設定項目：**
* **Shadow Type (陰影類型)**：調整文字的陰影樣式。
  * `None`：無陰影。
  * `Offset`：傳統的右下角偏移陰影。
  * `Outline`：全方位描邊（文字四周包覆外框），能大幅提升在複雜背景下的文字辨識度。
* **Baseline Adjust (基準線微調)**：由於不同 TTF 字型的重心位置不同，若發現文字垂直偏上或偏下，可透過此拉 Bar 微調文字整體的上下位置 (數值範圍：-10 ~ 15)。
* **Line Spacing (行距)**：調整多行文字之間的垂直距離 (數值範圍：-10 ~ 15)。
* **HiRes Text Draw (高解析度渲染)**：開啟 (Yes) 時，文字會以螢幕真實解析度進行平滑渲染；關閉 (No) 時，文字會配合遊戲的低解析度像素感進行縮放。
* **Force TTF English (強制英文字母使用 TTF)**：若開啟，遊戲中的英文字母也會強制使用您所選定的中文字型來繪製，確保中英文字體風格一致。**如果開啟HiRes Text Draw (高解析度渲染)，則此項設定無效。**
* **Scale UI (UI 縮放)**：決定 UI 介面是否要跟隨螢幕解析度進行縮放。

---

### 4.2 對話文字設定 (Dialog Text Setup)

管理 NPC 對話與飄字的設定。

* **Font Type (字型)**：選擇對話時要使用的字型檔。
* **Dialog Font Size (對話字型大小)**：調整與 NPC 對話時，顯示在畫面上的文字大小 (範圍：9 ~ 72)。
* **Overhead Font Size (頭頂飄字大小)**：調整 NPC 走動時頭頂彈出的對話氣泡，或是點擊物品時浮現的名稱標籤大小 (範圍：9 ~ 72)。
* **Letter Spacing (字元間距)**：調整中文字元之間的水平間隔。可設負數讓排版更緊密 (範圍：-5 ~ +5)。

---

### 4.3 書本/卷軸設定 (Small Text Setup)

針對書本和卷軸獨立設置，讓您能獲得不同的閱讀體驗。

* **Font Type (字型)**：選擇書本要使用的字型檔。如果您希望書本呈現手寫風或書法風，可以指定與對話不同的字型。**設定為Default時，則使用對話文字的字型檔。**
* **Book/Scroll Font Size (書本字型大小)**：調整閱讀書本與卷軸時的文字大小 (範圍：9 ~ 72)。
* **Letter Spacing (字元間距)**：獨立調整書本內的字元間隔，提升閱讀舒適度 (範圍：-5 ~ +5)。

---

### 4.4 招牌/墓碑設定 (Sign Text Setup)

管理遊戲中各種招牌、木牌、墓碑的文字設定。

* **Font Type (字型)**：選擇招牌要使用的字型檔。**設定為Default時，則使用對話文字的字型檔。**
* **Sign Font Size (招牌字型大小)**：調整點擊招牌或墓碑時顯示的文字大小 (範圍：9 ~ 72)。
* **Letter Spacing (字元間距)**：獨立調整招牌文字的字元間隔 (範圍：-5 ~ +5)。

> **備註**：招牌字型設定的獨立化，同時也是為了將來支援《巨蛇之島》(Serpent Isle) 的「翻譯術」相關顯示機制做鋪路。
