2. 設定與配置
2.1. 安裝

* 您需要 Exult 並且正確安裝（請參閱 ReadMe.txt）。同時請確保您使用的是最新的 Exult 快照版本。
  Exult Studio 只與最新的快照版本相容，不支援最新的正式發行版。
* 在 U*ix 平台上，您需要從 https://exult.info/download.html 取得的原始碼快照中自行編譯 Exult Studio。
* 在 Windows 平台（XP、Vista、7、8、10），請從我們的下載頁面下載 Exult Studio，並將其安裝到與 Exult 相同的資料夾中。
* macOS 使用者亦可在我們的下載頁面取得快照版本。下載磁碟映像後，將應用程式移至「應用程式」資料夾即可。


2.2. 執行 Exult Studio

您可以單獨執行 Exult Studio，但這樣做並沒有多大意義，因為它需要以 Exult 作為伺服器。您真正需要做的是：
* 將「exult_studio.glade」放入 Exult 的「data」資料夾（若您使用 Windows 或 macOS 的快照版本則不需要此步驟）。
* 確保「exult_studio」在您的系統路徑中（在 Windows 上，「exult_studio.exe」需要與 exult.exe 在同一個資料夾中）。
* 以視窗模式（非全螢幕）執行 Exult。
* 啟用 Exult 的作弊模式（請參閱 ReadMe.txt）。
* 按下「alt-ctrl-m」進入「地圖編輯」模式。若一切設定正確，exult_studio 將會啟動、連接到 Exult，並在其視窗左側顯示檔案清單。

個別重新啟動其中一個程式時，可重新連線：
* 若 Exult 未在執行，請啟動它，開始（或繼續）一個遊戲，然後按下「ctrl-alt-m」進入地圖編輯模式。在 Exult Studio 中點選「File - Open Game」選擇您要編輯的遊戲，然後按下「Connect」按鈕連接到正在執行的 Exult。
* 若 Exult Studio 未在執行，請啟動它，在「File - Open Game」對話方塊中選擇要編輯的遊戲，然後按下「Connect」按鈕連接到正在執行的 Exult。


2.3. 執行 Exult Studio 的逐步說明

上述說明對某些人來說可能仍過於技術性。在開始建構您的世界之前，您必須確保所有步驟都已完成。
1. 雖然不是絕對必要，但在您的電腦上正確安裝 BG 或 SI 的可運行副本會很有幫助。
2. 接下來，您需要在電腦上正確安裝最新的 Exult 快照版本且能正常運作。如果您目前在電腦上可以遊玩 BG 或 SI，那麼這可能已經完成了。為確認您擁有正確版本，請確認在 Exult 開始畫面中顯示 X.XX GIT（X.XX 代表某個版本號），例如 https://exult.info/images/screenshots/mainmenu.png。
3. 您也需要確保電腦上已正確安裝最新版本的 Exult Studio。Exult Studio 應安裝在與 Exult 快照相同的資料夾中。
4. 修補檔（patch）資料夾必須位於您有寫入權限的目錄中，這樣 Exult Studio 才能儲存對現有遊戲的修改。關於如何在 exult.cfg 中進行相應設定，請參閱「2.4. 目前可以做什麼」。
5. 為使 Exult Studio 正常運作，Exult 必須以視窗模式執行。如果您在遊戲的同時可以看到桌面，那就表示設定正確。
6. 確認已啟用作弊功能。這可以在遊戲的「遊玩選項」中啟用（請參閱 ReadMe.txt）。
7. 在以視窗模式執行 Exult 時，按下「ctrl-alt-m」進入地圖編輯模式。若一切操作正確，Exult Studio 應該會開啟。在地圖編輯模式下，世界會暫停，但您仍然可以移動角色以便放置物件。現在您可以開始進行世界編輯了。


2.4. 目前可以做什麼

* 在主視窗中瀏覽圖形。
* 從圖形瀏覽器將圖形拖曳到 Exult 中，該物件便會被放置在遊戲中。
* 雙擊一個「彩蛋（egg）」來進行編輯，應會出現一個編輯方塊。
* 使用 Exult Studio 的下拉選單建立新的「彩蛋」。在彩蛋編輯方塊中，按下「Apply」後，系統會提示您在 Exult 中點選您想放置彩蛋的位置。
* 若正在編輯「怪物」彩蛋，您可以從圖形瀏覽器將圖形拖曳到顯示怪物的區域，藉此設定怪物種類。
* 雙擊一個 NPC 來進行編輯，也可以使用下拉選單建立新的 NPC。屬性、旗標與行程都可以查看和修改。
* 雙擊其他物件來編輯其位置和品質。
* 瀏覽「u7chunks」檔案，並將其拖曳到 Exult 中以改變地形。在此瀏覽器中，您也可以建立新地形並修改其順序。
* 選取一個區塊，從「Mode」選單選擇「Paint with chunks」，然後用整個區塊塗繪地形。
* 在 Exult Studio 中勾選「Edit terrain」核取方塊來編輯「地形」（儲存於「u7chunks」中）。這是一種特殊模式，按住滑鼠左鍵拖曳可「塗繪」目前所選的圖形。請注意，一個「地形」通常在地圖的多個地方被使用，在一處修改也會影響其他所有相同的地形。
* 使用 Exult Studio 的「File - Save map」下拉選單儲存地圖。為避免無意中覆蓋檔案，原本應存入「static」資料夾的檔案，將改為存入您在「exult.cfg」中指定的「patch」資料夾。以下是編輯 BG 的範例：

<game>
  <blackgate>
    <title>
    blackgate
    </title>
    <path>
    ./blackgate
    </path>
    <patch>
    ./blackgate/patch
    </patch>
  </blackgate>
重要事項：Exult Studio 需要「patch」資料夾具有寫入權限。若您沒有寫入權限，請將其放置在您有權限寫入的位置，並在 exult.cfg 中相應修改路徑。
Exult 在啟動新遊戲時，若「patch」資料夾存在，也會從中讀取檔案。patch 資料夾應位於主遊戲資料夾內，與 static 資料夾並排。
在任何模式下，您都可以按住 Shift 鍵並點選來新增目前選取的圖形。

2.6. 命令列選項

Exult Studio 提供一些「隱藏」的命令列選項：
* (--help) -h
  顯示這些命令列選項。
* (--silent) -s
  不顯示遊戲狀態。
* (--config) -c configfile
  指定替代設定檔（支援相對路徑或絕對路徑）。
* (--game) -g GAMENAME
  指定 GAMENAME，Exult Studio 將從 exult.cfg 讀取遊戲基礎資料夾。GAMENAME 可從 exult.cfg 的 <game> 部分中指定的遊戲中選擇。
* (--mod) -m modname
  必須與「-g gamename」一起使用；使用標題等於「modname」的模組執行指定遊戲。「modname」是模組 cfg 檔案的名稱（例如 keyring.cfg 對應的 modname 為「keyring」）。
* (--xmldir) -x FOLDER
  告訴 exult_studio 在 FOLDER 中尋找其使用者介面規格（exult_studio.glade）。
  您可以輸入完整路徑（例如「exult_studio -xc:\exult\data」）到 glade 檔案，或使用相對路徑（例如 exult_studio -x./data）。
  此選項僅對想自行編輯 exult_studio.glade 的開發者有用。
* (--cssdir) -y FOLDER
  告訴 exult_studio 在 FOLDER 中尋找用於自訂 Exult Studio 外觀的 CSS 檔案（exult_studio.css）。
* (--portable) -p
  僅限 Windows 的可攜式選項。Exult Studio 將從 Exult 安裝的資料夾讀取 cfg 檔案。
* (--zoom) -z
  以 2、3、4、6、8、12、16、24 或 32 的倍數縮放圖形檢視。使用「-z 2」或「-z 2 b」也可以啟用雙線性濾鏡。

3. Exult Studio 基礎
3.1. 功能說明

當 Exult Studio 正確運行後，主視窗左側會顯示遊戲檔案的樹狀結構，右側則顯示目前所選檔案的詳細內容。

Exult Studio 所支援的檔案類型說明如下。


3.2. 圖形（Shape）檔案

圖形是遊戲的基本圖形元素。每個圖形包含一個或多個畫格，通常代表同一物品的不同狀態或角度。例如：一個按鈕圖形可以有「按下」和「放開」的畫格；一個角色可以有「坐著」、「站立朝向某方向」或「揮拳」等畫格。
當選取一個圖形檔案時，主視窗的右側會顯示其中所有圖形的第零個畫格。點擊圖形可以選取它，並會顯示其編號、畫格數以及名稱（如果已知）。可以透過更改畫格編號來查看其他畫格。
當所選檔案中的圖形具有名稱資訊時，您也可以使用尋找功能搜尋具有該名稱的圖形（例如在 shapes.vga 中可以搜尋「door」來找到所有具有門畫格的圖形）。您可以在所選檔案中向下或向上搜尋。
查看圖形時，可以按下 Exult Studio 右下角的「Frames」按鈕，將一個圖形的所有畫格並排顯示。
圖形檔案還有一個特殊的右鍵選單，請參閱 5.2.。
常見的圖形檔案有：
* Fonts.vga
  顯示遊戲中使用的所有文字圖形。
* Faces.vga
  包含所有對話圖片的圖形。
* Sprites.vga
  顯示所有可用於覆蓋畫面的動畫。
* Shapes.vga
  顯示可放置到世界中的物件。
* Gumps.vga
  顯示遊戲中使用的所有顯示介面圖形。
* Paperdoll.vga
  包含紙娃娃介面的圖形（目前僅限 SI）。
* Pointers.shp
  包含滑鼠游標的圖形。
* Combos.flx
  自訂組合物件的儲存位置。


3.3. 地圖檔案：U7CHUNKS

這些檔案包含所謂的「區塊（chunks）」，作為最終地圖的模板。所選地圖檔案的區塊會顯示在主視窗的右側。
選取一個區塊後，您有以下兩個選項：
* Locate（定位）
  顯示該區塊在 Exult 遊戲中的使用位置。
* Move（移動）
  在區塊檔案中移動區塊，這不會影響地圖上的顯示。

在區塊上按右鍵會出現另外兩個選項（以及 File-save/revert 選項）：
* New...（新增）
  Empty（空白）：建立一個新的空白區塊。將新區塊拖曳到遊戲中，然後透過拖曳圖形到其上來進行編輯。
  Duplicate（複製）：將區塊複製到區塊清單的底部。將複製的區塊拖曳到地圖上進行編輯。
* Delete（刪除）
  刪除該區塊。請謹慎使用此選項。


3.4. 地圖檔案：NPC

此處列出遊戲中所有的 NPC——查看此清單需要 Exult Studio 連接到 Exult。選取 NPC 後，其編號和名稱會顯示在 NPC 顯示區域下方，您也可以捲動瀏覽其畫格，或按下「Frames」按鈕將所有畫格排成一列顯示。
選取一個 NPC 後，您有以下兩個選項：
* Find（尋找）
  輸入 NPC 的名字，即可在清單中搜尋並反白顯示該 NPC。
* Locate（定位）
  顯示該 NPC 目前在 Exult 遊戲中所在的位置。


3.5. 調色盤（Palettes）檔案

遊戲使用的調色盤儲存在此處列出的檔案中。
選取一個調色盤檔案後，主視窗右側會顯示編號為零的調色盤。選取其他編號可查看其他調色盤。選取調色盤檔案後，您有一些選項：
* Edit（編輯）
  New/Remove：新增或刪除一個調色盤。
* Move（移動）
  在檔案中移動調色盤。
* File（檔案）
  Import（匯入）：用調色盤文字檔覆蓋目前的調色盤。
  Export（匯出）：將目前的調色盤匯出為文字檔。

調色盤文字檔與 GIMP 相容。
在調色盤上按右鍵只會出現預設的 File-save/revert 選項。


3.6. 詳細視窗

在詳細視窗下方，您有以下選項：
* Frame（畫格）：
  選擇要顯示的畫格。
* Frames（畫格列表）
  將圖形的所有畫格並排顯示。
* Find（尋找）
  讓您在群組中搜尋指定的圖形。
* Locate（定位）
  在遊戲中定位所選圖形。它只定位圖形，而非特定的畫格。


3.7. 群組（Groups）檔案

當您必須從包含多個畫格的眾多圖形檔案中進行選擇時，編輯遊戲可能會變得相當繁瑣。為了讓這項工作更容易，我們實作了「群組」功能，可以將多個圖形歸納在一起。例如，您可以將所有包含門畫格的圖形歸納到一個名為「doors」的群組中。
為此，您需要選取「Groups」，在視窗下方輸入名稱，然後點選「New」建立新群組。之後您可以在「Shape Menu」中選擇將圖形加入此群組。
雙擊一個群組可開啟群組視窗，其中顯示群組內的圖形，選取圖形後會顯示其資訊。您也有一些選項可以編輯群組：
* Move（移動）：在群組內移動圖形。
* Remove（移除）：從群組中移除圖形。
* Name（名稱）：更改群組的名稱。
* Frame（畫格）：選擇要顯示的畫格。
* Frames（畫格列表）：將圖形的所有畫格並排顯示。
* Find（尋找）：讓您在群組中搜尋指定的圖形。
* Locate（定位）：在遊戲中定位所選圖形，只定位圖形而非特定畫格。

我們也允許對所選群組進行一些基本操作：
* Export/Import（匯出/匯入）：將群組匯出至/從 .grp 檔案匯入，藉此與其他使用者分享群組。
* Clone（複製）：建立所選群組的副本。
* Delete（刪除）：刪除所選群組。

對於 shapes.vga 檔案，我們提供一些內建群組，您可以在群組清單中開啟或複製它們。

4. Exult Studio 選單
4.1. 概覽

在開始建構您自己的小世界之前，了解 Exult Studio 的結構和選單排列是很重要的。以下是部分 Exult Studio 選單的概覽。

注意：某些選單項目只有在 Exult Studio 連接到 Exult 時才可用，未連線時這些項目會呈灰色且無法選取。


4.2. File（檔案）選單

* New Game...（新遊戲）
  讓您開始製作新遊戲。Jeff 撰寫了詳盡的使用說明，請參閱《新遊戲手冊》。
* New Mod...（新模組）
  輕鬆為現有遊戲開始製作新模組。開啟的對話方塊可讓您選擇要修改的遊戲、模組名稱及其在 Exult 選單中顯示的名稱。
* Open Game...（開啟遊戲）
  選擇您要製作的遊戲或模組。
* Save all（全部儲存）「Ctrl-S」
  儲存地圖、圖形資訊、群組和您編輯的預設值。如果您對更改內容感到滿意，請在退出前執行此操作，否則所有工作都將遺失。
* New...（新增）
  Shapes file...（圖形檔案）：讓您選擇要建立新 vga 檔案的資料夾，並要求您輸入名稱（例如 mygame.vga）。
  Single shape file...（單一圖形檔案）：讓您選擇要建立新 shape 檔案的資料夾，並要求您輸入名稱（例如 mygame.shp）。
* Save...（儲存）
  Map（地圖）：儲存已編輯遊戲的地圖。
  Shape info（圖形資訊）：儲存您對圖形資訊所做的更改。
  Groups（群組）：儲存群組設定。
  Combos（組合）：儲存組合檔案。
* Presets（預設值）
  儲存您在圖形和 NPC 編輯器中建立的預設值。
* Reload...（重新載入）
  Map（地圖）「Ctrl-R」：重新載入地圖，自上次儲存後的所有更改都將被捨棄。
  Usecode：當您編輯遊戲的 usecode 時非常有用，通常這需要重新啟動 Exult。
  Style CSS：若您修改了 exult_studio.css，可以在不重新啟動的情況下重新載入。
* Connect（連接）
  當其中一個程式需要重新啟動時，用於連接 Exult 和 Exult Studio。
* Preferences（偏好設定）
  Image Editor Command（圖片編輯器命令）：當您右鍵點擊圖形時，執行所選的圖片編輯器。
  Image-Edit Filetype（圖片編輯格式）：選擇圖片編輯器使用的檔案格式。
  Default Game Name（預設遊戲名稱）：選擇 Exult Studio 預設開啟的遊戲。
  Shape List Background（圖形清單背景）：選擇不同的背景顏色，以便更清楚地看到圖形。
* Prompts（提示）
  重設所有您能夠永久關閉的警告或對話提示。
* Exit（退出）「Ctrl-Q」
  退出 Exult Studio。

請注意，儲存和建立新檔案的預設位置是遊戲的 PATCH 資料夾。若未指定 PATCH 資料夾，Exult Studio 將自動建立一個。請參閱「2.4. 目前可以做什麼」。


4.3. Edit（編輯）選單

* Cut（剪下）「Ctrl-X」
  移除選取的物件並放入記憶體。
* Copy（複製）「Ctrl-C」
  將選取的物件複製到記憶體。
* Paste（貼上）「Ctrl-V」
  顯示十字游標，並在您點擊的位置將記憶體中的物件複製到遊戲中。
* Properties...（屬性）
  顯示選取物件的屬性。若選取了多個物件，則顯示最後一個選取物件的屬性。只有 NPC 和彩蛋的屬性與選取「Basic properties」時有所不同。
* Basic properties...（基本屬性）
  顯示選取物件的屬性。
* Create egg...（建立彩蛋）
  建立或編輯彩蛋。詳細資訊請參閱「6. 彩蛋編輯」。
* Create NPC...（建立 NPC）
  建立或編輯 NPC。詳細資訊請參閱「7. NPC 編輯」。
* Create Barge...（建立大型載具）
  建立大型載具，例如魔法地毯或馬車。詳細資訊請參閱「12.2.」。
* Set Game Information（設定遊戲資訊）
  編輯在 Exult 選單中顯示的遊戲資訊。

在地圖編輯模式下，您可以在 Exult 中左鍵點擊選取圖形，或按住 Ctrl 左鍵點擊選取多個圖形。


4.4. Mode（模式）選單

描述在地圖編輯時滑鼠在 Exult 中的行為方式。
* Move（移動）
  這是正常模式，您可以用滑鼠拖曳物件，或單擊以識別物件。被選取的物件會以紅色外框顯示。按住「Ctrl」同時選取可選取多個物件。
* Paint（繪製）
  左鍵單擊可插入最後從「shapes.vga」選取的圖形，按住左鍵拖曳可在每個圖格插入該圖形。按住 Alt 鍵，將會隨機繪製目前選取圖形的各個畫格（對草地區域很方便）。
* Paint with chunks（以區塊繪製）
  與一般繪製模式相同，但使用區塊。左鍵點擊可將目前的區塊繪製到地圖上。請參閱「9.7.」。
* Pick for Edit（選取以編輯）
  允許大量選取物件，無需按住「Ctrl」，只需按住左鍵移動滑鼠即可選取所有物件。
* Pick for Combo（選取以建立組合）
  選取物件以建立新的組合檔案。請參閱「8.1.」。
* Select chunks（選取區塊）
  您可以選取區塊並使用「ctrl-方向鍵」移動它們。

請注意，只有在「Move」模式下才能在遊戲視窗中拖曳物件。


4.5. Tools（工具）選單

* Locator...（定位器）「Ctrl-L」
  顯示目前遊戲視窗在整個地圖中的位置，並允許您透過雙擊位置或拖曳小方框來移動視圖。
* Write Minimap（寫入小地圖）
  寫入目前遊戲的小地圖（minimaps.vga）。
* New Combo...（新增組合）
  建立新的組合檔案。請參閱「8.1.」。
* Unused shapes...（未使用的圖形）
  搜尋整個建構中的世界，查看 shapes.vga 中是否有任何圖形未被使用。
* Compile Usecode...（編譯 Usecode）
  編譯 patch 資料夾中的 usecode 腳本。
* Fix old shape info...（修復舊版圖形資訊）
  將舊版 Exult Studio 丟失的圖形資訊重新加回舊的模組和修補檔中。
* Audio Tester...（音訊測試器）
  透過 Exult 播放音樂、語音和音效。


4.6. Map（地圖）選單

* New（新增）
  建立新地圖，以支援多地圖功能（請參閱「12.1.」）。
* Main/Map #xx（主地圖/地圖 #xx）
  預設地圖或目前正在製作的地圖。


4.7. 工具列

* Connect/Disconnect（連接/中斷連接）
  連接或中斷 Exult Studio 與 Exult 的連線。
* Play/Edit（遊玩/編輯）
  等同於在 Exult 中按下「alt-ctrl-m」。退出地圖編輯模式讓您遊玩遊戲，按「Edit」再次進入地圖編輯模式。
* Grid（格線）
  在遊戲視窗中顯示白色格線，以便更好地控制物件的放置位置。
* 3D Bounding boxes（3D 邊界框）
  切換遊戲視窗中物件周圍 3D 邊界框的顯示。
* Hide lift（隱藏高度以上的物件）
  隱藏位於所選高度以上的物件。
* Edit terrain（編輯地形）
  請參閱「2.4.」。請注意，地形在地圖的多個位置被使用，在一處修改會影響所有其他相同的地形。
* Zoom（縮放）
  放大或縮小圖形瀏覽器中的圖形。
* Bilinear（雙線性）
  切換圖形瀏覽器中圖形的雙線性濾鏡。

5. 圖形編輯器
5.1. 圖形屬性視窗

雙擊一個圖形可開啟「圖形資訊」視窗，提供對圖形行為和外觀各方面的詳細編輯功能。視窗使用分頁標籤將眾多屬性組織成合理的類別。
圖形資訊是一個非常全面的編輯器，但大部分內容一目了然。選擇某個類別或特定旗標可能會開啟更多包含附加選項的分頁。


5.2. 圖形右鍵選單

在圖形瀏覽器（例如 Files-Shapes.vga）中，對圖形按右鍵可獲得一些編輯選項：
* File（檔案）
  Save（儲存）：儲存此圖形。
  Revert（還原）：還原對此檔案的修改。
* Info...（資訊）
  與雙擊圖形相同，在編輯器中顯示資訊。資訊透過「4.2. File（檔案）」儲存。
* Edit...（編輯）
  在您的圖片編輯器中開啟所選畫格。在圖片編輯器中儲存後，Exult Studio 將在 5 秒內讀取變更。
* Edit tiled（以拼貼方式編輯）
  僅適用於「平坦」（8x8）圖形。將所有畫格合併成一張圖片在圖片編輯器中開啟。對於製作大量地形畫格（如草地）非常方便。
* New frame（新增畫格）
  在目前選取的畫格之後建立一個新畫格。「Insert」鍵也可以執行此操作。
* Export/Import frame（匯出/匯入畫格）
  從 .png 檔案匯入單一畫格，或將畫格匯出為 .png。
* Export/Import all frames（匯出/匯入所有畫格）
  匯入/匯出所有畫格。匯入時 .png 檔案需以基本名稱加上畫格編號命名（例如 shape00.png、shape01.png）。
* Export/Import shape（匯出/匯入圖形）
  從 .png 檔案匯入單一畫格，或將畫格匯出為 .png。
* New shape（新增圖形）
  提供對話方塊，讓您選擇圖形編號以及初始畫格數。也可以從 TrueType 或 Type1 字型檔案建立新的字型圖形。


5.3. 圖形預設值

您可以儲存預設值，並將其套用到任何圖形。
要儲存預設值，請開啟您想使用的圖形，輸入預設值名稱，然後按下「New」按鈕。要將預設值套用到圖形，請從下拉清單中選取預設值，然後按下「Apply」。
您也可以透過輸入圖形編號並按下「Apply from Shape #」按鈕，套用尚未儲存為預設值的圖形屬性。
此外，您可以匯出/匯入、複製、重新命名和刪除預設值。

6. 彩蛋編輯
6.1. 彩蛋說明

彩蛋最簡單的形式是放置在世界中、但對一般使用者不可見的物件。當玩家滿足彩蛋的觸發條件時，彩蛋就會被啟動。彩蛋可以觸發從怪物生成、背景音樂改變到自訂 usecode 執行等各種事件。建議您在地圖編輯模式下放置彩蛋，因為彩蛋在此模式下不會啟動。然後切換回正常遊玩模式測試彩蛋的效果。


6.2. 不同類型的彩蛋

目前 Exult Studio 支援以下類型的彩蛋（詳情見後）：
* Monster（怪物生成）
  當特定條件滿足時可以生成一個生物，通常是當角色靠近彩蛋到一定距離內。它也允許在聖者靠近時出現簡單的物件，如牆壁或家具。
* Jukebox（點唱機）
  當角色進入特定區域時設定背景音樂。
* Sound Effect and Voice（音效和語音）
  當角色滿足彩蛋條件時，播放所選的音效。
* Voice（語音）
  當角色滿足彩蛋條件時，播放語音音軌。
* Usecode（Usecode 腳本）
  當彩蛋的條件滿足時，允許啟動自訂 usecode。
* Missile（投射物）
  建立有趣的物件，例如火焰噴射器陷阱。
* Teleport（傳送）
  當特定條件滿足時，將聖者傳送到地圖上的任何位置。
* Weather（天氣）
  臨時設定遊戲內的天氣。
* Path（路徑）
  將傳送彩蛋的目的地設定為特定物件。
* Button（按鈕）
  用於啟動附近設定為「external（外部）」的彩蛋。
* Intermap（跨地圖）
  此彩蛋可用於在地圖之間建立傳送器。


6.3. 新增、移除和編輯彩蛋

建立彩蛋最方便的方式是從「Edit」選單選取「Create new egg」。這會彈出「Exult Egg」視窗，您可以在此選擇要建立的彩蛋類型及其屬性。當您對彩蛋感到滿意後，按下「Apply」，然後在 Exult 中右鍵點擊您想放置彩蛋的位置。要移除彩蛋，請在地圖編輯模式下選取它，然後按下「ctrl-DEL」。要編輯彩蛋，請在地圖編輯模式下雙擊它。


6.4. 彩蛋的屬性

在選擇彩蛋類型之前，您可以編輯彩蛋的基本屬性：
* Criteria（觸發條件）
  非常重要，設定啟動彩蛋所需滿足的條件。選項包括：
  Cached in（載入記憶體時）：彩蛋所在的區塊被載入記憶體時啟動，通常發生在距離數個螢幕之遠的地方。
  Party near（隊伍靠近）：當玩家控制的角色或任何隊員進入指定距離範圍內時啟動。
  Avatar near（聖者靠近）：與「Party near」相同，但只追蹤主角的移動。
  Avatar far（聖者遠離）：當您離開指定距離範圍時彩蛋被啟動，非常適合從背後發動的偷襲。
  Avatar footpad（聖者踏上）：聖者必須實際踏上彩蛋的位置才能觸發。
  Party footpad（隊伍踏上）：主角或任何同伴踏上彩蛋時啟動。
  Something on（物件進出）：當物件在彩蛋指定的區域內被放置和移除時啟動。
  External（外部）：將由附近的按鈕彩蛋啟動。
* Probability（觸發機率）
  彩蛋被啟動的機率。設定為 100 確保每次滿足條件時都會啟動；設定為 0 則永遠不觸發；0 到 100 之間的值使啟動成為隨機事件。
* Flags（旗標）
  Nocturnal（夜行）：設定此屬性的彩蛋只會在夜間啟動。
  Hatched（已孵化）：建立一個已經被啟動的彩蛋，它是不活躍的。
  Once-Only（僅一次）：設定此旗標的彩蛋只會啟動一次，然後消失。
  Auto-reset（自動重設）：每次滿足條件時都會繼續啟動。
* Distance（距離）
  設定角色需要距離彩蛋多遠才能啟動它。每個距離單位等於一個圖格（8x8 像素）。


6.5. 放置怪物生成彩蛋

在放置怪物生成點之前，考慮彩蛋的基本屬性：機率、距離、是否夜行。然後設定怪物特定的屬性。切換到 Exult Studio 主視窗，選取 shapes.vga 並選擇一個圖形，將其拖放到「Exult Egg」視窗上。
您還需要設定生成怪物的陣營：「Neutral（中立）」會忽略聖者直到被攻擊；「Evil（邪惡）」會立即攻擊聖者；「Good（善良）」會幫助聖者但會攻擊邪惡怪物；「Chaotic（混亂）」會攻擊任何人。
使用「count」選項設定要出現的生物數量（1 到 31 隻）。
設定完彩蛋後，按下「Apply」並將彩蛋放置在世界地圖上。


6.6. 怪物與生物的行程

您可以使用 NPC 擁有的所有行程，但對於生成的怪物，最常用以下行程：

* Horiz. Pace（水平踱步）：生物會水平地來回踱步，適合守衛和哨兵。
* Vert. Pace（垂直踱步）：與水平踱步相同，但方向改為垂直。
* Hound（追蹤）：生物會慢慢跟隨主角，適合不肯放棄的生物。
* Stand（站立）：生物會站在原地，直到有更好的理由移動。
* Loiter（遊蕩）：生物會漫無目的地遊蕩，以隨機方向小幅移動。
* Wander（閒逛）：生物會在相當大的區域內緩慢移動。
* Wait（等待）：生物會安靜地待在原地。
* Shy（膽小）：生物害怕主角，會慢慢遠離聖者。
* Waiter（服務員）：生物像有目的地一樣在擁擠的區域來回奔走。
* Graze（吃草）：與「遊蕩」非常相似，但更傾向於留在一個區域。
* Duel（決鬥）：將兩個設定此行程的中立生物放在一起，就會形成混戰。
* Patrol（巡邏）：NPC 會跟隨「路徑」標記（圖形 #607）。


6.7. 點唱機、音效和語音彩蛋

使用這些彩蛋非常簡單，選擇您想要的音效、音樂曲目或錄製的數位語音，然後將其放置到地圖上。當角色啟動彩蛋時，它們就開始播放。您可以設定音樂和音效以持續循環播放。
當 Exult Studio 連接到 Exult 時，您可以按下播放按鈕來測試音訊。


6.8. Usecode 彩蛋

Usecode 彩蛋有許多不同的功能。關於 Usecode 彩蛋選單，最重要的是「function number」欄位，您在此輸入此彩蛋將執行的 usecode 函式的十六進位值。


6.9. 投射物彩蛋

放置投射物彩蛋時，首先需要設定彩蛋的觸發屬性。您也可以設定陷阱啟動時的射擊方向（8 個基本方向之一）。
使用延遲計時器設定投射物流的連續性。設定為 1 可形成持續的投射物流，設定為 10 則使危險偶發。請勿將計時器設定為 0 秒。


6.10. 傳送彩蛋

傳送彩蛋的主要用途是立即將角色從一個地方移動到另一個地方。
第一種模式是透過指定大地圖上的 x 和 y 座標來選擇傳送目的地。第二種模式是按下「use coordinates」按鈕，將傳送目標指向有編號的路徑彩蛋，優點是可以傳送到建築物的上層。


6.11. 天氣彩蛋

天氣彩蛋有兩個屬性：
* Weather（天氣）：
  Halt（停止）：停止目前所有天氣，恢復晴朗預設狀態。
  Snow（雪）：雪花、雲朵以及第 18 首音樂播放。
  Rain（雨）：雨、大量雷電、雲朵。
  Sparkle（閃光）：類似雨的效果，使聖者無法使用魔法法術。
  Fog（霧）：白霧和一些雨滴。
  Overcast（陰天）：一些雲朵，最多兩朵投下陰影。
  Clouds（多雲）：更多的雲朵，部分相互重疊。
* Duration（持續時間）：設定天氣的持續時間，以遊戲時間計算，最長 255 分鐘。


6.12. 路徑彩蛋

路徑彩蛋用於手動放置個別傳送目的地。給路徑彩蛋一個唯一的編號，然後將傳送彩蛋指向它。
注意：它只能在每個方向最多 256 個圖格的距離內有效，且不會跨越世界邊界。


6.13. 按鈕彩蛋

按鈕彩蛋能夠啟動附近所有設定為「external（外部）」的彩蛋。您可以透過增加「distance」設定來擴大影響區域，每個距離單位等於 1 個圖格（8x8 像素）。


6.14. 跨地圖彩蛋

跨地圖彩蛋的運作方式與普通傳送彩蛋完全相同，但它可以在地圖之間傳送主角。「Coordinates」選項設定傳送目的地的精確圖格位置，「Map Number」條件設定主角將出現在哪張地圖上。

7. NPC 編輯
7.1. 編輯現有的 NPC

要使用 Exult Studio 編輯 NPC，您需要在 Exult 中執行遊戲，並且 Exult Studio 也在執行中。啟用地圖編輯並雙擊您想編輯的 NPC，Exult Studio 的 NPC 視窗將彈出，顯示 NPC 的所有數據。


7.2. 建立新的 NPC

如果您想建立新的 NPC，請在「Edit」選單中選取「Create NPC」。這將彈出 NPC 視窗，請輸入新 NPC 的所有屬性。當您對新 NPC 感到滿意後，按下「Apply」，系統會要求您在 Exult 中選擇放置 NPC 的位置。


7.3. NPC 基本設定

* Face #（外觀編號）
  從 Faces.vga 將外觀拖放到 NPC 視窗的外觀欄位，或輸入外觀編號，也可以使用 +/- 按鈕選取。
* Name（名稱）
  為您的 NPC 選擇一個名稱。
* Usecode
  在此輸入與 NPC 關聯的 usecode。
* NPC #（NPC 編號）
  此項無法更改。
* Ident（識別碼）
  這是 SI 中 usecode 使用的編號，用於區分不同的 NPC 可能性。
* Shape #（圖形編號）
  從 shapes.vga 將圖形拖放到此行，或輸入圖形編號，也可以使用 +/- 按鈕選取。
* Frame #（畫格編號）
  NPC 開始時所使用的圖形畫格。
* Alignment（陣營）
  Neutral（中立）：按照行程行動，直到被攻擊，但若目擊聖者偷竊或殺害中立/善良 NPC，會呼叫守衛。
  Good（善良）：在戰鬥中幫助聖者，但忽略偷竊或謀殺行為，會攻擊邪惡怪物或 NPC。
  Evil（邪惡）：聖者進入戰鬥模式時立即遭受攻擊，部分 NPC 會一見到您就攻擊。
  Chaotic（混亂）：忽略偷竊或謀殺行為，但會幫助其他混亂陣營的 NPC。
* Attack Mode（攻擊模式）
  選擇 NPC 進入戰鬥時的攻擊模式：Nearest（最近）、Weakest（最弱）、Strongest（最強）、Berserk（狂暴）、Protect（保護）、Defend（防禦）、Flank（側翼）、Flee（逃跑）、Random（隨機）或 Manual（手動）。不建議使用 Manual。


7.4. NPC 屬性

NPC 的重要屬性設定在「Properties」分頁中：
* Strength（力量）
* Dexterity（敏捷）
* Intelligence（智力）
* Health（生命值）
* Combat（戰鬥）
* Mana（魔力）
  剩餘可用於施放法術的魔力。只有隊伍成員且遊戲允許隊員施放法術時才有用。
* Max. Mana（最大魔力）
  可擁有的最大魔力值。
* Training（訓練點）
  NPC 剩餘可在訓練師處使用的訓練點數。只對隊伍成員有用。
* Experience（經驗值）
  只對隊伍成員有用。
* Food Level（飢餓值）
  NPC 有多餓。只與隊伍成員相關，普通 NPC 不會挨餓。


7.5. NPC 旗標

在此您可以設定 NPC 的特殊屬性。某些屬性只針對特殊 NPC、隊伍成員或聖者。許多屬性也只在 SI 中可用。
* Asleep（睡眠）
* Confused（困惑）
* Dancing（跳舞）
* Fly（飛行）
* In motion（移動中）
* Invisible（隱形）
* No Magic（無魔法）
* Petra
* Protection（保護）：當您對 NPC 施放保護法術時，此旗標會被設定。
* Swim（游泳）：允許 NPC 在水上行走。
* Might（神力）
* Bleeding（流血）：NPC 會流血，移動時留下血跡。
* Conjured（召喚）
* Don't render (BG) / Don't move (SI)：使 NPC 變得不可見或無法移動。
* Freeze（冰凍）：NPC 感到寒冷，需要更暖的衣物。
* In party（在隊伍中）：NPC 是隊伍的成員。
* Met（已見面）：聖者之前曾與此 NPC 交談過。
* Don't move (BG) / Don't render (SI)：使 NPC 變得不可見或無法移動。
* Poisoned（中毒）
* Female（女性）
* Tattooed（有刺青）
* Walk（行走）：未設定此旗標的 NPC 無法移動。
* Charmed（被魅惑）
* Cursed（被詛咒）
* Ethereal（虛體）：使 NPC 能夠像幽靈一樣行動（穿越牆壁、在水上行走……）。
* In action（行動中）
* Read（閱讀）：此 NPC 可以閱讀符文或蛇形文字（對聖者有用，可直接閱讀告示牌）。
* Naked（裸體）
* Paralyzed（麻痺）
* Polymorph（多形態）
* Summoned（被召喚）
* Tournament（比武）：在戰鬥中此 NPC 無法死亡。
* Zombie（殭屍）


7.6. NPC 行程

在此分頁中，您可以設定 NPC 正常遵循的行程。
* Activity（活動）
  按下「Set」按鈕可選擇行程。請記住，某些行程也需要相應的物品。若要清除活動，將其設定為「--None--」。
* Location（位置）
  輸入您想讓 NPC 遵循其行程的位置 x、y 和 z 座標。z 座標設定行程在哪個樓層開始。將聖者放置在預定活動地點，按下「Game」按鈕，Exult Studio 將自動填入座標。
  另一種設定座標的方式是點擊「Set in game」，然後在 Exult 中點擊所需位置。
  也可以在某個位置按下「F2」，作弊畫面會顯示座標。
* Locate（定位）
  這會將地圖中心移動到行程設定的位置。


7.7. NPC 預設值

您可以儲存預設值，並將其套用到任何 NPC。預設值會儲存 NPC 的所有屬性，名稱和 usecode 除外。
要儲存預設值，依照您的需求設定 NPC，輸入預設值名稱，然後按下「New」按鈕。要將預設值套用到 NPC，從下拉清單中選取預設值，然後按下「Apply」。此外，您還可以匯出/匯入、複製、重新命名和刪除預設值。
有了這個功能，您可以快速建立一組守衛、店主或其他常用的 NPC。

8. 基本編輯器
8.1. 建立組合檔案

透過選取「Tools - New Combo」建立「組合圖形」，例如柵欄或整片屋頂。第一次執行 Exult Studio 時，系統會自動在「Patch」資料夾中建立一個名為 combos.flx 的檔案。在「Modes」選單中選取「Pick for Combo」，應會彈出一個空白視窗。在遊戲視窗中，雙擊您想加入組合的物件，它們應該會出現在視窗中（也可以按住右鍵滑過所有要加入的物件）。然後選取物件並微調其位置。完成後按下「Apply」，組合將暫時儲存，直到您按下「Save all」為止。
您可以將組合物件拖放到遊戲視窗中。


8.2. 自訂 Usecode

如前所述（參閱 1.3.），Usecode 實際上是驅動《創世紀 7》以及使用 Exult Studio 建立的任何遊戲的核心。
目前我們還沒有 Usecode 編輯器/除錯器，因此編寫自己的 Usecode 並不容易，但也並非非常困難。
關於 Usecode 的範例，請從我們的下載頁面下載 BG 的 SF Island 模組，其中包含 usecode.uc（usecode 腳本）和 usecode 檔案。
使用 ucc 處理 usecode.uc（例如「ucc -o usecode usecode.uc」），可以得到 usecode 檔案。
Marzo 在他的網站 Seven Towers 撰寫了詳盡的教學以及最新的函式庫列表。

9. 基本地圖編輯
9.1. 學習地圖編輯基礎

在讓 Exult Studio 正確運行後，可能首先想做的事就是開始建立自己的小世界。第一步是學習如何移動物件和區塊，以及從 Exult Studio 將物品放置到遊戲世界中。最好的學習方式是使用現有的遊戲，例如 BG 或 SI。


9.2. 移動物件

使您的世界真正獨特的最簡單方法，是先移動現有的建築物。在 Exult Studio 中「Move（移動）」是預設選項。當地圖上出現紅色格線時，表示您處於地圖編輯模式。您可以用滑鼠選取任何物件（被選取的物件以紅色反白）並四處移動，採用簡單的拖放方式。唯一無法拖放的是區塊。您也可以選取物件並按下「ctrl-方向鍵」來更改物件的 x 和 y 座標，按下「ctrl-page up」或「ctrl-page down」可更改 z 座標。


9.3. 如何從 Exult Studio 放置物件

只需從 shapes.vga 選單中選取一個圖形，然後將其拖曳到 Exult 中即可。一旦找到物件要出現的位置，放開滑鼠，物件就放置好了。如果對放置的位置不滿意，直接拖放到其他地方即可。
從 Exult Studio 拖曳時，您會看到一個綠色格線，顯示物件確切將出現的位置。


9.4. 標記、刪除、複製和建立多個物件

要標記多個物件，請按住「Ctrl」並點擊您想標記的物件。
若要移除物件，請選取它並按下「ctrl-x」（剪下，放入記憶體）。若不想保留，按下「ctrl-DEL」直接刪除。若要移動物件，使用「Paste（貼上）」（ctrl-v）在新位置放置。要建立多個副本，使用「Copy（複製）」（ctrl-c）後再多次「Paste（貼上）」。


9.5. 製作懸浮物件，例如橋梁

透過在格線高度選單中更改值來設定物件的 z 高度。若希望角色能夠在物件下方行走，物件必須設定在角色所行走表面以上 4 個格線高度。若希望角色能夠在物件上行走，物件的頂部必須距離角色目前所在的表面不超過 1 個格線高度。


9.6. 如何更改物件的畫格

選取物件使其反白顯示為紅色，然後在「Edit」選單中選取「Basic Properties（基本屬性）」，或按住「Ctrl」雙擊物件。「Exult Object」方塊讓您選取不同的畫格，也允許您手動設定物件的高度。
您也可以使用「ctrl-KP+」和「ctrl-KP-」來操控選取物件的畫格，使用「ctrl-KP*」可以旋轉物件，這些快速鍵也可同時用於多個選取的物件。


9.7. 如何更改區塊（大紅色外框正方形）

要更改地圖上的大塊地形，您必須放置一個區塊而非圖形。可用的各種區塊位於「U7chunks」標題下。要放置區塊，方式與放置圖形相同，但請記住區塊只能放置在地圖編輯格線的紅色方格內。

若您想對預製區塊做一些細微調整，透過選取「Edit terrain（編輯地形）」選項，可以透過直接在區塊上放置物件來修改它，這樣做會永久更改您正在編輯的區塊，請謹慎操作。
注意：當您編輯一個區塊時，遊戲中所有相同的區塊都會改變。要只編輯其中一個，請進入區塊選單，右鍵點擊該區塊並選取「New -> Duplicate」，建立一個副本後再進行編輯。


9.8. 如何建立由多個物件組成的結構

許多結構都由多個物件組成，例如屋頂、長段牆壁或柵欄。選取「Tools - New Combos」選項，然後在遊戲視窗中雙擊所有您計劃加入的物件（也可以按住右鍵滑過所有物件）。
隨著您點選每個物件，選取內容會出現在組合視窗中。給物件命名後點擊「Okay」，物件將暫時儲存在 combos.flx 中，可以正常放置在地圖上。


9.9. 組合物件的更多操作

可以在組合建立器視窗中選取各個物件，透過更改它們的顯示順序確保所有物件正確顯示。也可以使用 x、y、z 座標在組合中移動各個物件。若加入了不想保留的物件，選取該物件並按下「Remove（移除）」即可。


9.10. 使用繪製功能快速建立森林

要快速且方便地建立多個物件，使用「Paint（繪製）」選項。從圖形選單中選取樹木，然後從「Mode」選單中選取「Paint」選項。選取 Exult 視窗，您現在可以使用綠色格線快速放置多個物件。
