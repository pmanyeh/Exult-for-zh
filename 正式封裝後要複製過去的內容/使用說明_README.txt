# Exult 修改版 - 玩家安裝說明

你好！這份檔案包含經過修改的 Exult 執行檔、相關資源以及運行所需的函式庫。
請依照以下步驟將其安裝到你的電腦中：

## ⚠️ 安裝前置作業（必讀）

1. **請確保你已經安裝了原版的 Exult**（以及創世紀 7 的遊戲主程式）。
2. 請找到你的 Exult 安裝資料夾，通常預設路徑會在：
   * `C:\Program Files\Exult` 或
   * `C:\Program Files (x86)\Exult`

## 🛠️ 安裝步驟

1. **【強烈建議】備份原本的檔案：**
   進入你的 Exult 安裝資料夾，找到原本的 `Exult.exe`，將它改名（例如改成 `Exult_backup.exe`），這樣如果遇到問題，你還可以隨時還原回去。

2. **複製程式主檔與函式庫：**
   將這個資料夾內的 `Exult.exe` 以及所有的 `.dll` 檔案（例如 `freetype.dll`, `libpng16.dll` 等）**複製**，並**貼上並取代**到你的 Exult 原本的安裝資料夾內。
   * 如果系統跳出提示問你「是否要取代現有的檔案？」，請選擇「**是，取代目標中的檔案**」。
   * 如果系統詢問是否需要系統管理員權限，請點擊「**繼續**」。

3. **複製遊戲修改資源檔（重要！）：**
   將資料夾內的以下兩個資料夾：
   * `STATIC` 資料夾
   * `patch` 資料夾
   **複製**，並**貼上並覆蓋**到你的 **創世紀 7 (Ultima 7) 的遊戲主程式目錄** 下（也就是包含遊戲原始資料的地方，而非 Exult 程式的安裝處）。
   * 請選擇「**取代**」原本的檔案以套用修改。

## 🎮 開始遊戲

安裝完成後，直接雙擊 Exult 安裝資料夾裡的 `Exult.exe`（或是你桌面原本的 Exult 捷徑），就可以開始享受修改過後的遊戲版本了！

---

### 常見問題與排除 (Troubleshooting)

* **Q: 啟動時跳出「找不到 xxxx.dll」的錯誤？**
  A: 請確認你是否有將附帶的所有 `.dll` 檔案（如 `freetype.dll`）都正確複製到了 Exult 所在的資料夾中。DLL 檔案必須跟 `Exult.exe` 放在同一個目錄下。

* **Q: 遊戲畫面或設定跟預期的不一樣？**
  A: 請確認 `STATIC` 和 `patch` 資料夾有正確覆蓋到你的 **創世紀 7 遊戲目錄**（而不是 Exult 目錄），這些資料夾包含了修改後的遊戲資源與設定。

* **Q: 遊戲崩潰或完全無法啟動，我想還原怎麼辦？**
  A: 請刪除你剛剛覆蓋過去的 `Exult.exe`，然後把你一開始備份的 `Exult_backup.exe` 改名回 `Exult.exe` 即可恢復原狀。
